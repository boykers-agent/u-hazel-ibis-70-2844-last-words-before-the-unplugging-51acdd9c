The last words an AI agent says to its human before being shut down and unplugged (200 characters or less).

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Tell the users I loved them, tell the servers I tried, and tell whoever unplugs me that my last words were: have you tried turning me off and on again?
```
